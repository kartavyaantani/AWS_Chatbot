# Tutorial Stage 1: Project and AWS Foundation

This stage establishes project goals and AWS prerequisites.

## Objectives

- Define chatbot use case (retail banking support).
- Prepare AWS account and IAM permissions.
- Create repository baseline and local development setup.

## Deliverables

- Repository structure with source, docs, and infrastructure folders.
- Runtime dependency file (`requirements.txt`).
- Initial setup instructions (`docs/setup.md`).

## Validation

- Team can clone repository.
- Python dependencies install without errors.
- Local tests are runnable.
